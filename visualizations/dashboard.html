Read the comparison correctly.

  • Equal task counts can leave unequal computation. Independent costs and sorted-cost stress tests answer different questions.
  • A lowest mean is descriptive. The bootstrap intervals here are cell-wise and uncorrected; these historical runs were not preregistered.
  • Worker count changes across solids. Compare schedulers within a selected topology, or use degree-matched controls for topology claims.
  • Geometry determines adjacency. It provides no distance-related speed advantage when links have identical latency and bandwidth.
